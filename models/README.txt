OPTIONAL LOCAL MODEL
====================
For a completely self-contained deployment, place the CC BY-SA 4.0 file
'ecorche.glb' from https://github.com/Charleeh/ecorche/tree/main/model
in this directory. The app automatically prefers ./models/ecorche.glb.

Without that file, the app loads the same model from jsDelivr when online,
and its service worker caches the model for subsequent offline use.
