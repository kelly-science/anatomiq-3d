# AnatomIQ 3D 2.0.3 — Nervous Visual Tuning

## Focus

A visual refinement pass for the nervous system after the 2.0.2 deep-brain and meningeal update.

## Included changes

- More realistic pink cortical rendering for the cerebrum.
- Different default colors for key internal nervous-system groups to make deep-brain anatomy easier to distinguish in class.
- Translucent meningeal rendering for dura-based meshes.
- More specific explanatory text for ventricular, meningeal, basal-ganglia, thalamic and hypothalamic structures.

## No model rebuild required

This release is **app-only**. Your existing `nervous-standard.glb`, `nervous-detailed.glb`, and `nervous-structures.json` stay unchanged.

## Deployment

Patch the app files, test locally, then upload the changed JavaScript and `version.json` together.
